# PhoSem 

PIN 다이오드 die 이미지에서 미세 결함을 검출하는 MIL 기반 다중 라벨 분류 노트북입니다.

## 배경

반도체 제조 공정에서 PIN 다이오드 die는 육안 검사만으로는 놓치기 쉬운 미세한 결함(이물질, 스크래치, 접합 불량, 끊어짐, 파손 등)을 가진 채 다음 공정으로 넘어가는 경우가 있습니다. 이 노트북은 die 이미지를 입력으로 받아 이러한 결함 유무와 유형을 자동으로 판별하는 딥러닝 파이프라인을 구현합니다.

## 핵심 아이디어

### 1. 다중 인스턴스 학습 (MIL)

die 이미지 전체를 하나의 라벨로 학습시키는 단순한 방식은, 실제로는 결함이 없는 영역까지 '불량'으로 학습되는 노이즈 문제를 일으킵니다.

이를 피하기 위해 하나의 die를 여러 개의 작은 patch 묶음으로 나누고, 그 묶음 중 가장 의심스러운 부분을 기준으로 die 단위 판정을 내리는 **다중 인스턴스 학습(MIL, Multiple Instance Learning)** 방식을 사용합니다. 결함이 실제로 존재하는 위치에 학습 신호가 집중되고, 정상 영역이 불필요하게 오염되지 않는다는 장점이 있습니다.

### 2. 다중 라벨 구조

결함은 한 가지 유형으로만 나타나지 않고 여러 유형이 동시에 나타나거나 새로운 조합으로 발생할 수 있습니다. 이를 반영해 단일 클래스 분류가 아닌 **다중 라벨(multi-label)** 구조를 채택했습니다. 결함 유형별로 독립적인 판정을 두어, 조합이 늘어나거나 특정 유형의 데이터가 적더라도 유연하게 대응할 수 있도록 설계했습니다.

## 진행 흐름

1. 원본 이미지 및 라벨 정리
2. 학습/검증 데이터 분리
3. MIL 기반 모델 구성과 학습
4. 결과 집계 및 판정 기준 결정
5. 실제 평가 배치 적용
